# MORENT — Car Rental Design Project

![MORENT Preview](https://images.unsplash.com/photo-1555215695-3004980ad54e?w=1200&q=80)

MORENT is a premium, modern, and fully responsive Car Rental Platform design. This project focuses on high-end aesthetics, smooth user experience, and a clean interface built entirely with semantic HTML5 and Vanilla CSS3.
## Deployment link
https://final-html-css-project-pi.vercel.app/
## 🚀 Key Features

- **Dynamic Landing Page**: Features hero banners, pick-up/drop-off forms, and curated car categories.
- **Advanced Filtering**: Sidebar for filtering cars by type (Sport, SUV, MPV, etc.), capacity, and price range.
- **Detailed Car View**: Comprehensive car details including specifications, image galleries, and user reviews.
- **Seamless Checkout Flow**: Mockup of a multi-step payment and booking process.
- **Responsive Design**: Optimized for all devices, from desktop monitors to mobile phones.
- **Modern UI/UX**: Uses "Plus Jakarta Sans" typography, glassmorphism effects, and a professional color palette.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Custom styles using Flexbox and Grid layouts.
- **Font Awesome**: High-quality vector icons for UI elements.
- **Google Fonts**: Custom typography with "Plus Jakarta Sans".

## ⚙️ How to Run the Project

Since this is a front-end design project, it does not require any build tools or complex setup.

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/kongnyuroger/final-HTML-CSS-Project.git
   ```
2. **Navigate to the Directory**:
   ```bash
   cd final-HTML-CSS-Project
   ```
3. **Open in Browser**:
   Double-click `index.html` or open it using a live server extension in your preferred IDE (like VS Code's "Live Server").

## 🗺️ Navigation Guide

The project is structured to demonstrate a complete user flow:

1. **Home (`index.html`)**: Explore available cars, use the search bar, or filter by category. Click **"Rent Now"** on any car card to view more details.
2. **Car Details (`detail.html`)**: View specifications, switch between car photos in the gallery, and read user reviews. Click **"Rent Now"** again to proceed to booking.
3. **Checkout (`payment.html`)**: Fill in the booking forms, select a payment method (Credit Card, PayPal, or Bitcoin), and complete your rental.
